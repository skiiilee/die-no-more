# 2단계 · 화면 와이어프레임 (Low fidelity)

> **2단계 화면 설계 초안:** 실제 앱 화면/구현 코드가 아닌 **텍스트 기반 레이아웃 스케치**다. 모바일을 우선하며, 컬러·아이콘·여백·타이포그래피 최종 결정은 하지 않는다. **승인됨 (2026-11-12, [ADR-0003](../decisions/ADR-0003-implementation-decisions.md) D1).** 선택지·알림 규칙은 [05 검토본](05-pc-mo-wireframe-snapshot.md)을 우선한다.  
> 관련: [정보 구조](01-information-architecture.md) · [기능 명세](03-functional-specification.md).

## 1. 화면 공통 원칙

- 주요 탐색 초안: **오늘 | 내 식물 | 건강 점검 | 더보기**.
- 현재 화분 이름·사진·날짜를 항상 명확하게 표기. 같은 종의 화분도 구분.
- 실내 사진 외부 전송 전에는 그 사실을 안내하고 사용자가 명시적으로 진행.
- 건강 분석의 불확실성과 사용자가 입력한 관리 정보의 '검토 전' 상태를 눈에 띄게 표기.
- 모든 폼은 취소/이전 이동이 가능하며 저장하지 않은 값이 사라질 때 경고.
- 도식 안의 괄호/구획은 구조 표현이며 코드 컴포넌트가 아니다.

## 2. S02 · 오늘 / 홈

```text
┌──────────────────────────────────────┐
│ Die No More                  [설정]   │
│ 오늘, 식물은 어떠세요?                │
│                                      │
│ [건강 점검하기]   [새 식물 등록]      │
│                                      │
│ 나의 식물  3개    관리할 일  2개     │
│ ┌──────────────────────────────────┐ │
│ │ 오늘 확인할 일                    │ │
│ │ 몬스테라 A · 흙 상태 확인 [보기]  │ │
│ │ 스투키     · 관찰 기록   [보기]   │ │
│ └──────────────────────────────────┘ │
│ 최근 관찰                            │
│ ┌──────────────────────────────────┐ │
│ │ 몬스테라 A · 잎 끝 갈변 · 11/09   │ │
│ └──────────────────────────────────┘ │
│ [오늘] [내 식물] [건강 점검] [더보기] │
└──────────────────────────────────────┘
```

**기능:** 건강 점검과 식물 등록이 언제나 접근 가능. '오늘 확인할 일' 및 [전체 보기]를 누르면 **S09 관리할 일 목록** 또는 해당 화분의 작업으로 이동한다. S02 '할 일 상태'에는 **예정/기한 지남/완료/미룸/건너뜀** 상태별 건수를 표시한다. **빈 상태:** '등록된 식물이 없어요' + '첫 식물 등록하기'. 미완료 할 일이 없다면 '오늘 확인할 일이 없어요'.

## 4. S03 → S04 → S05 · 신규 식물 등록

### S03: 식물 추가 — 이름 검색과 사진 스캔을 처음부터 함께 표시

```text
┌──────────────────────────────────────┐
│ [×] 식물 추가                        │
│ 사진으로 확인하거나 이름으로 찾아요  │
│                                      │
│ [🔍 식물 이름 검색____] [📷 식물 스캔]│
│                                      │
│ [검색어 입력 시]                      │
│ ┌──────────────────────────────────┐ │
│ │ 몬스테라 델리시오사              │ │
│ │ Monstera deliciosa     [선택]    │ │
│ │ 다른 이름·학명·품종명 후보 ...    │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [데이터가 있는 경우에만]             │
│ 추천/최근 검색 식물 목록 (선택 사항) │
│                                      │
│ [검색 결과 없음 / 이름 직접 입력]    │
│ [종을 모르겠어요]                    │
└──────────────────────────────────────┘
```

**핵심:** 사용자가 화면에 진입하는 즉시 **검색창과 식물 스캔 버튼이 같은 단계에서 동시에 보이고 활성화**되어야 한다. 이름 검색은 한국어 이름·학명·품종명으로 가능하며, 검색 후보는 한국어 이름과 학명 등 확인에 필요한 정보를 보여준다. 위의 몬스테라는 **레이아웃 예시일 뿐 초기 저장 데이터가 아니다.** 초기 종별 관리 DB는 0건이므로 목록을 미리 채우지 않으며, 추천/인기 목록은 실제 제공 가능한 출처가 있을 때만 표시한다.

**사진 스캔 선택 시:** [식물 스캔] → 촬영/갤러리 선택 **모달** → S03-P에서 업로드 사진 1~5장 확인·삭제·추가 → [사진으로 식물 찾기] → **S04-A** 후보 확인. S03-P에는 별도 전송 동의 화면·체크박스를 두지 않는다. 카메라 권한 거부·사진/파일 오류·API 장애 때도 같은 S03의 이름 검색 또는 직접 입력이 가능하며, 사진 스캔은 등록의 필수 단계가 아니다.

### S03: [식물 스캔] 클릭 시 촬영/갤러리 선택 모달 (PC/MO)

```text
┌────────────────────────────────────────┐
│ 사진 선택                            │
│                                        │
│ [카메라로 촬영] → 촬영 후 S03-P        │
│ [갤러리에서 선택] → 선택 후 S03-P      │
│ [취소] → S03                          │
└────────────────────────────────────────┘
```

### S03-P: 업로드한 사진 목록 및 식물 찾기

```text
┌────────────────────────────────────────┐
│ < 업로드한 사진 (S03-P)                │
│                                        │
│ 선택한 사진 목록 (1~5장)               │
│ [사진1 미리보기] [삭제]                │
│ [사진2 미리보기] [삭제]                │
│                                        │
│ [+ 사진 추가] → 촬영/갤러리 선택 모달  │
│ [사진으로 식물 찾기] → S04-A           │
│ [이름 검색으로 돌아가기] → S03         │
└────────────────────────────────────────┘
```

**화면 동작:** 촬영 또는 갤러리 선택은 S03의 모달에서 진행하고, **S03-P는 업로드한 사진 목록·개별 삭제·사진 추가·[사진으로 식물 찾기]만 제공**한다. S03-P에는 별도의 전송 동의 확인 단계가 없다. 사진을 추가할 때는 촬영/갤러리 선택 모달을 다시 연다. [사진으로 식물 찾기]로 Pl@ntNet 식별을 시작하고 결과는 기존 **S04-A 후보 목록**에서 표시한다. PC 카메라는 연결된 카메라를 사용할 수 있을 때만 선택 가능하다.

### S04-A/B: 후보 목록 → 종별 정보 미리보기 → 추가 여부 선택

**1) S04-A: 검색/스캔으로 찾은 후보 목록**

```text
┌──────────────────────────────────────┐
│ < 검색 결과                   2 / 3   │
│ [🔍 몬스테라____________________]      │
│                                      │
│ [참고사진] 몬스테라 델리시오사 [보기]│
│        Monstera deliciosa            │
│ [사진없음] 다른 후보          [보기]│
│        학명/품종명                    │
│                                      │
│ [다른 이름 검색] [종을 모르겠어요]   │
└──────────────────────────────────────┘
```

**후보 이미지 규칙:** API가 제공한 참고 사진이 있을 때만 후보 썸네일을 표시한다. 사진이 없으면 '사진 없음'을 표시하고 이름·학명 선택은 그대로 가능하다. 사용자가 올린 사진을 후보 참고 사진인 것처럼 표시하지 않는다.

**2) S04-B: 사용자가 후보를 누르면 나오는 식물 정보 화면 (등록 전)**

```text
┌──────────────────────────────────────┐
│ < 식물 검색 결과 상세                │
│ ┌──────────────────────────────────┐ │
│ │        식물 사진 (있을 때)        │ │
│ └──────────────────────────────────┘ │
│ 몬스테라 델리시오사                  │
│ Monstera deliciosa                   │
│                                      │
│ 기본 정보                            │
│ · 관리 난이도   [정보가 있으면 표시] │
│ · 빛 환경       [정보가 있으면 표시] │
│ · 짧은 식물 설명 [정보가 있으면 표시]│
│ * 자료가 없으면 '정보 없음' 표시     │
│                                      │
│ [이 식물 추가하기]                   │
│ [다른 식물 찾기]                     │
└──────────────────────────────────────┘
```

**동작:** 검색 결과는 식물DB에 저장할 수 있지만, 화분(내 식물)으로는 저장하지 않는다. 먼저 사용자가 식물의 한국어 이름·학명·사진(있을 경우), 실제 확인 가능한 간단 정보를 읽은 뒤 **'이 식물 추가하기'를 명시적으로 눌러야만 S05 화분 등록 화면으로 진행**한다. S05의 '식물 등록하기'에서 비로소 개별 화분이 저장된다. '다른 식물 찾기'는 후보 목록/검색으로 복귀한다.

**정보 표시 범위:** 화면의 몬스테라와 기본 정보 항목은 **구성 예시**다. 초기 종별 관리 DB 0건 원칙을 유지하며, 관리 난이도·빛 조건·설명 등의 정보가 없을 때는 내용을 지어내거나 AI를 자동 호출하지 않고 '정보 없음'으로 안내한다. 검색은 Perenual·Trefle, 스캔은 Pl@ntNet, 종 관리 정보는 Perenual을 사용한다 (`04-data-sources.md` 참고). 사진 스캔 결과도 같은 방식으로 요약 확인 후 추가 가능하며, 결과 없음·오인식·한국어 이름 없음에는 수동 입력/종 미상 경로가 유지된다.

### S05: 내 화분 저장 + 초기 관리 상태

```text
┌──────────────────────────────────────┐
│ < 내 화분 등록                3 / 3   │
│ 사진 미리보기                        │
│ 식물 이름 : 몬스테라 델리시오사       │
│ 화분 별명(선택) [______________]     │
│ 관리 장소  [거실 창가____________]    │
│ 실내/실외 [실내 ▼]                   │
│                                      │
│ ─ 지금까지 어떻게 관리했나요? ─      │
│ 마지막으로 물 준 시기 [선택 ▼]       │
│  당일 ~ 1일 전 / 일주일 전           │
│  한달 전 / 모름                      │
│                                      │
│ 빛이 얼마나 들어오나요? [선택 ▼]     │
│  직사광선 / 밝은 간접광 / 보통        │
│  약함 / 잘 모르겠음                  │
│                                      │
│ 마지막 분갈이 시기 [선택 ▼]          │
│  당일 ~ 1일 전 / 일주일 전           │
│  한달 전 / 2~3개월 / 3-6개월         │
│  6개월 이상 / 1년 이상               │
│                                      │
│ 화분의 재질 [선택 ▼]                 │
│  플라스틱 / 테라코다,도기 / 유리      │
│  자기,석기 세라믹 / 화단             │
│                                      │
│ 알림 설정                            │
│ [ ] 물 알림    [ ] 비료 알림         │
│                                      │
│ 추가 메모 [_____________________]    │
│ [식물 등록하기]                      │
│ 별명 미입력 시 식물 이름 표시         │
└──────────────────────────────────────┘
```

**기능:** 화분 별명은 선택이며 비워도 등록할 수 있고, 표시 시 식물 이름을 사용한다. 모바일의 S05 기본 정보와 초기 관리 환경은 두 단계가 아니라 **한 화면에서 이어지는 단일 스크롤 양식**이다. 마지막 물 준 시기와 마지막 분갈이 시기는 **정확한 날짜가 아닌 선택한 경과 기간**으로 화분별 초기 상태에 저장한다. 선택값을 임의 날짜로 환산해 과거 물주기·분갈이 실행 이력을 자동 생성하지 않는다. 채광과 화분 재질은 해당 화분의 현재 환경·용기 정보로 저장한다. 물 알림과 비료 알림은 **각 화분에서 별도로 켜고 끄는 설정**이다. 분갈이 선택지는 [05 검토본](05-pc-mo-wireframe-snapshot.md) 규칙 1의 10개 구간을, 알림 노출과 일정은 규칙 2와 ADR-0003 D16을 따른다.

**저장 후:** S06 화분 상세로 이동. **종별 관리 정보 부재**는 오류가 아니라 '아직 관리 정보 없음' 상태이며 S13으로 선택적으로 연결.

## 5. S06 · 화분 상세

```text
┌──────────────────────────────────────┐
│ < 내 식물        몬스테라 A [수정]    │
│ ┌──────────────────────────────────┐ │
│ │           화분 사진              │ │
│ └──────────────────────────────────┘ │
│ 몬스테라 델리시오사 · 거실 창가       │
│ [건강 점검] [관리 기록] [사진 추가]   │
│                                      │
│ 관리 정보                            │
│ [기존 관리 정보 보기] 또는          │
│ [아직 없어요 · 직접 입력하기]        │
│                                      │
│ 오늘 확인할 일: 흙 상태 확인 [보기]  │

│ [전체 이력 보기]                     │

```

**기능:** 종 공통 정보와 해당 화분만의 사진/기록/할 일 분리. 관리 정보 없는 상태에서도 건강 점검과 기록 가능.

```text
│ 결과는 확정 진단이 아닙니다          │
│                                      │
│ 관찰된 증상: 잎 끝 갈변              │
│                                      │
│ 가능한 원인(예시)                    │
│ 1. 과습 가능성 · 추가 확인 필요      │
│ 2. 건조 스트레스 가능성              │
│                                      │
│ 먼저 확인할 내용                     │
│ □ 흙 상태를 직접 확인                │
│ □ 최근 물주기 기록 확인              │
│ □ 잎 뒷면 및 줄기 사진 추가           │
│                                      │
│ 불확실성: 사진만으로 원인 확정 불가   │
│ [이 화분에 결과 저장] [다시 점검]    │
└──────────────────────────────────────┘
```

**주의:** 결과 문구는 **레이아웃용 가상 예시**로서 실제 식물 진단이나 권고가 아니다. AI가 잘 모르겠다고 응답하면 '판단 어려움'을 표시. 분석 장애 또는 사진 전송 비동의 시 관찰 기록으로 돌아갈 수 있음.

## 7. S08 · 통합 관리 행동 및 관찰 기록

```text
┌────────────────────────────────────────────┐
│ < 관리 기록 (S08)     화분: [선택 ▼]      │
│ 공통 수행 날짜/시간   [수정 가능 ▼]       │
│                                            │
│ [ ] 실제 물주기   물의 양(선택) [___]    │
│ [ ] 비료 주기     메모(선택) [____]      │
│ [ ] 분갈이        메모(선택) [____]      │
│ [ ] 가지치기      메모(선택) [____]      │
│ 흙 상태(선택)  ( )마름 ( )적당 ( )젖음      │
│              ( )잘 모르겠음              │
│ 잎/해충/환경 관찰(선택) [____________]    │
│ 사진(선택)  [첨부]                       │
│ 공통 메모(선택) [___________________]     │
│                                            │
│ [기록 저장하기]                          │
└────────────────────────────────────────────┘
```

**기능:** 관리 행동을 선행 선택해 화면을 전환하지 않는다. **모든 항목이 한 화면에 동시에 보이고 선택 입력**이다. 입력·체크한 항목만 실제 이력으로 생성한다. 아무 항목도 작성하지 않으면 빈 기록을 저장하지 않는다. 흙 상태 확인은 급수 로그와 구분하고, 다중 입력 후 저장하더라도 동일 행동의 중복 이력을 만들지 않는다.

## 8. S09 · 관리할 일 / 다중 선택 상태 변경

**PC: 체크박스 상시 노출**

```text
┌────────────────────────────────────────────┐
│ < 관리할 일        [예정][완료][미룸]...  │
│ [ ] 전체 선택                              │
│ [ ] 화분 A · 흙 상태 확인  [완료][미루기]   │
│ [ ] 화분 B · 물 주기       [완료][미루기]   │
│ [ ] 화분 C · 비료 주기     [완료][미루기]   │
│                                            │
│ [선택 완료] [선택 미루기] [선택 건너뛰기] │
└────────────────────────────────────────────┘
```

**모바일: 평상시 목록 → 선택 모드**

```text
┌─────────────────────────────────────┐
│ < 관리할 일                         │
│ [상태 한 번에 바꾸기]               │
│ 화분 A · 흙 상태 확인 [완료][미루기] │
│ 화분 B · 물 주기      [완료][미루기] │
│                  ↓ 버튼 클릭        │
│ [ ] 화분 A · 흙 상태 확인            │
│ [ ] 화분 B · 물 주기                 │
│ [ ] 화분 C · 비료 주기               │
│ [선택 완료] [선택 미루기]            │
│ [선택 건너뛰기] [취소]              │
└─────────────────────────────────────┘
```

**기능:** 여러 할 일을 선택하여 하나의 상태로 일괄 변경한다. PC 체크박스는 상시 노출, 모바일은 상단 버튼 클릭 후 선택 모드에서만 체크박스를 표시한다. 실제 급수 항목 완료 시에는 수행 여부 확인이 필수이며 미루기/건너뛰기로 실제 활동 로그를 만들지 않는다. 일부 실패 시 성공·실패 항목을 구분해 표시한다.

## 9. S13 · 종별 관리 정보 직접 입력

```text
┌──────────────────────────────────────┐
│ < 몬스테라 관리 정보                 │
│ 관리 정보가 아직 없어요              │
│ [직접 입력하기]  ← 빈 입력 양식 열기  │
│                                      │
│ --- 입력 화면 ---                    │
│ [사용자 입력 · 검토 전]               │
│ 빛       [____________________]      │
│ 물       [____________________]      │
│ 온도     [____________________]      │
│ 흙       [____________________]      │
│ 주의사항 [____________________]      │
│ 참고 자료(선택) [____________]       │
│                                      │
│ [변경사항 저장] [검토 완료 승인]      │
└──────────────────────────────────────┘
```

**기능:** 버튼을 누르면 사용자가 내용을 직접 입력하는 양식이 열리며, AI 요청은 발생하지 않는다. 입력 정보의 검토 전/검토 완료를 구분하고 사용자 승인 없이 자동 승인하지 않는다. 동일 종의 관리 정보는 새 화분 등록 때 재사용.

## 10. 기타 화면의 구조

| 화면 | 주요 화면 구성 | 상태별 예외 |
|---|---|---|
| S01 개인 진입 | 앱 이름, 개인 사용자 접근, 오류 복구 | 미로그인/세션 만료/접근 불가 |
| S10 이력 | 사진 썸네일, 날짜·활동 유형, 상세 관찰, 날짜 필터 | 이력 없음, 사진 표시 실패, 기록 제거 확인 |
| S12 더보기 | 개인 데이터/사진 관리, 외부 분석·개인정보 안내, 사용량·알림 설정 | 데이터 삭제 경고, 외부 서비스 점검 불가 |

## 11. 데스크톱 배치 제안

```text
┌─────────────────────────────────────────────────────────┐
│ Die No More                             [개인 설정]    │
├──────────────┬──────────────────────────────────────────┤
│ 오늘         │ 현재 선택 화면 제목                       │
│ 내 식물      │ ┌────────────────────┐ ┌───────────────┐ │
│ 건강 점검    │ │ 주 콘텐츠/화분     │ │ 오늘 할 일    │ │
│ 더보기       │ │ 사진/폼/결과      │ │ 최근 이력     │ │
│              │ │                    │ │               │ │
│              │ └────────────────────┘ └───────────────┘ │
└──────────────┴──────────────────────────────────────────┘
```

**적응 규칙:** 모바일은 단일 컬럼 + 하단 탐색, 데스크톱은 측면 탐색 + 화면 목적에 따른 1~2컬럼. 데스크톱에서도 데이터 입력과 건강 점검 결과의 의미는 동일.

## 12. 화면 상태 점검표 (설계 범위)

| 상태 | 적용 화면 | 화면에 있어야 할 내용 |
|---|---|---|
| 초기 데이터 없음 | S02/S11/S06/S13 | 빈 상태 설명과 다음 행동 |
| 카메라/파일 오류 | S03/S07 | 원인·지원 형식·재시도/수동 경로 |
| AI 대기 | S04/S07 | 처리 중 표시, 중복 실행 방지 |
| 분석 불확실 | S04/S07 | '판단 어려움', 수동 확인 및 추가 사진 |
| 서비스 장애/한도 초과 | S03/S07 | 비용 발생 없이 재시도 또는 일반 기능 계속 |
| 검토 전 관리 정보 | S06/S13 | 사용자 입력·검토 전 상태와 사용자 검토 동작 |
| 저장 실패/오프라인 | S05/S08/S09/S13 | 저장되지 않았음을 명확히 알리고 입력 보호 |
| 접근 제한 | S01/개인 데이터 | 개인정보를 화면에 노출하지 않고 접근 복구 안내 |

**설계 경계:** 위는 화면 구획과 문구 초안만 담는다. HTML/React 구현, 배포, 데이터베이스 생성, API 연동, UI 최종 승인 모두 포함하지 않는다.
