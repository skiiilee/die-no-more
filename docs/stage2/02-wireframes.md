# 2단계 · 화면 와이어프레임 (Low fidelity)

> **2단계 화면 설계 초안:** 실제 앱 화면/구현 코드가 아닌 **텍스트 기반 레이아웃 스케치**다. 모바일을 우선하며, 컬러·아이콘·여백·타이포그래피 최종 결정은 하지 않는다. 사용자 검토/수정은 3단계에서 진행한다.  
> 관련: [정보 구조](01-information-architecture.md) · [기능 명세](03-functional-specification.md).

## 1. 화면 공통 원칙

- 주요 탐색 초안: **오늘 | 내 식물 | 건강 점검 | 더보기**.
- 현재 화분 이름·사진·날짜를 항상 명확하게 표기. 같은 종의 화분도 구분.
- 실내 사진 외부 전송 전에는 그 사실을 안내하고 사용자가 명시적으로 진행.
- 건강 분석의 불확실성과 사용자가 입력한 관리 정보의 '검토 전' 상태를 눈에 띄게 표기.
- 모든 폼은 취소/이전 이동이 가능하며 저장하지 않은 값이 사라질 때 경고.
- 도식 안의 괄호/구획은 구조 표현이며 코드 컴포넌트가 아니다.

## 2. S02 · 오늘 / 홈

```text
┌──────────────────────────────────────┐
│ Die No More                  [설정]   │
│ 오늘, 식물은 어떠세요?                │
│                                      │
│ [건강 점검하기]   [새 식물 등록]      │
│                                      │
│ 나의 식물  3개    관리할 일  2개     │
│ ┌──────────────────────────────────┐ │
│ │ 오늘 확인할 일                    │ │
│ │ 몬스테라 A · 흙 상태 확인 [보기]  │ │
│ │ 스투키     · 관찰 기록   [보기]   │ │
│ └──────────────────────────────────┘ │
│ 최근 관찰                            │
│ ┌──────────────────────────────────┐ │
│ │ 몬스테라 A · 잎 끝 갈변 · 11/09   │ │
│ └──────────────────────────────────┘ │
│ [오늘] [내 식물] [건강 점검] [더보기] │
└──────────────────────────────────────┘
```

**기능:** 건강 점검과 식물 등록이 언제나 접근 가능. '오늘 확인할 일'을 누르면 S09 또는 해당 화분의 작업으로 이동. **빈 상태:** '등록된 식물이 없어요' + '첫 식물 등록하기'. 미완료 할 일이 없다면 '오늘 확인할 일이 없어요'.

## 3. S11 · 내 식물 목록

```text
┌──────────────────────────────────────┐
│ < 내 식물                    [+추가]  │
│ [화분 이름·종 검색______________]     │
│ [전체] [관찰 필요] [보관함]           │
│                                      │
│ [사진] 몬스테라 A                     │
│        몬스테라 · 거실 창가          │
│        최근 관찰: 11/09  [상세]       │
│ ──────────────────────────────────── │
│ [사진] 몬스테라 B                     │
│        몬스테라 · 안방                │
│        최근 관찰: 11/02  [상세]       │
│                                      │
│ [오늘] [내 식물] [건강 점검] [더보기] │
└──────────────────────────────────────┘
```

**기능:** 같은 종의 두 화분을 별도 카드로 표시, 닉네임/종/장소 검색, 보관된 화분과 현재 화분 구분. **빈 상태:** '식물이 아직 없어요. 등록부터 시작해 보세요.'

## 4. S03 → S04 → S05 · 신규 식물 등록

### S03: 식물 추가 — 이름 검색과 사진 스캔을 처음부터 함께 표시

```text
┌──────────────────────────────────────┐
│ [×] 식물 추가                        │
│ 사진으로 확인하거나 이름으로 찾아요  │
│                                      │
│ [🔍 식물 이름 검색____] [📷 식물 스캔]│
│                                      │
│ [검색어 입력 시]                      │
│ ┌──────────────────────────────────┐ │
│ │ 몬스테라 델리시오사              │ │
│ │ Monstera deliciosa     [선택]    │ │
│ │ 다른 이름·학명·품종명 후보 ...    │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [데이터가 있는 경우에만]             │
│ 추천/최근 검색 식물 목록 (선택 사항) │
│                                      │
│ [검색 결과 없음 / 이름 직접 입력]    │
│ [종을 모르겠어요]                    │
└──────────────────────────────────────┘
```

**핵심:** 사용자가 화면에 진입하는 즉시 **검색창과 식물 스캔 버튼이 같은 단계에서 동시에 보이고 활성화**되어야 한다. 이름 검색은 한국어 이름·학명·품종명으로 가능하며, 검색 후보는 한국어 이름과 학명 등 확인에 필요한 정보를 보여준다. 위의 몬스테라는 **레이아웃 예시일 뿐 초기 저장 데이터가 아니다.** 초기 종별 관리 DB는 0건이므로 목록을 미리 채우지 않으며, 추천/인기 목록은 실제 제공 가능한 출처가 있을 때만 표시한다.

**사진 스캔 선택 시:** 카메라/갤러리에서 사진 1–5장 선택 → 외부 식별 서비스로 보내기 전 사진 전송 안내/동의 → S04 후보 확인. 카메라 권한 거부·사진/파일 오류·API 장애 때도 같은 S03의 이름 검색 또는 직접 입력이 가능하며, 사진 스캔은 등록의 필수 단계가 아니다.

### S04: 검색·스캔 결과 중 식물 종류 확인

```text
┌──────────────────────────────────────┐
│ < 식물 종류 확인             2 / 3   │
│ 이름 검색 또는 스캔 결과를 확인해요  │
│                                      │
│ ( ) 몬스테라 델리시오사             │
│     Monstera deliciosa · 후보 1      │
│ ( ) 필로덴드론 ...  · 후보 2         │
│ ( ) 기타 후보 ...  · 후보 3          │
│                                      │
│ [직접 검색·입력]                     │
│ [종을 모르겠어요]                    │
│                                      │
│ [이 종류로 계속]                     │
│ * 후보 순위는 확정 판정이 아닙니다.   │
└──────────────────────────────────────┘
```

**상태:** 이름 검색/사진 스캔 어느 경로든 후보 없음·여러 후보 비슷함·한국어 이름 없음 → 학명 표기 및 수동 이름 입력, 종 미상 등록 허용. 스캔 후보나 검색 결과를 자동 확정하지 않음.

### S05: 내 화분 저장 + 초기 관리 상태

```text
┌──────────────────────────────────────┐
│ < 내 화분 등록                3 / 3   │
│ 사진 미리보기                        │
│ 식물 이름 : 몬스테라 델리시오사       │
│ 화분 별명* [몬스테라 A____________]   │
│ 관리 장소  [거실 창가____________]    │
│ 실내/실외 [실내 ▼]                   │
│                                      │
│ ─ 지금까지 어떻게 관리했나요? ─      │
│ 마지막으로 물 준 시기 [선택 ▼]       │
│  당일 ~ 1일 전 / 일주일 전           │
│  한달 전 / 모름                      │
│                                      │
│ 빛이 얼마나 들어오나요? [선택 ▼]     │
│  직사광선 / 밝은 간접광 / 보통        │
│  약함 / 잘 모르겠음                  │
│                                      │
│ 마지막 분갈이 시기 [선택 ▼]          │
│  당일 ~ 1일 전 / 일주일 전           │
│  한달 전 / 2~3개월 / 3-6개월         │
│  6개월 이상 / 1년 이상               │
│                                      │
│ 화분의 재질 [선택 ▼]                 │
│  플라스틱 / 테라코다,도기 / 유리      │
│  자기,석기 세라믹 / 화단             │
│                                      │
│ 알림 설정                            │
│ [ ] 물 알림    [ ] 비료 알림         │
│                                      │
│ 추가 메모 [_____________________]    │
│ [식물 등록하기]                      │
│ * 각 관리 항목은 선택값으로 입력     │
└──────────────────────────────────────┘
```

**기능:** 마지막 물 준 시기와 마지막 분갈이 시기는 **정확한 날짜가 아닌 선택한 경과 기간**으로 화분별 초기 상태에 저장한다. 선택값을 임의 날짜로 환산해 과거 물주기·분갈이 실행 이력을 자동 생성하지 않는다. 채광과 화분 재질은 해당 화분의 현재 환경·용기 정보로 저장한다. 물 알림과 비료 알림은 **각 화분에서 별도로 켜고 끄는 설정**이며, 실제 알림 주기·발송 방식은 아직 확정하지 않는다. 분갈이 시기 선택지에 '모름/분갈이 경험 없음'이 없고 '6개월 이상'과 '1년 이상'이 겹친다는 점은 추후 검토가 필요한 상태로 남긴다.

**저장 후:** S06 화분 상세로 이동. **종별 관리 정보 부재**는 오류가 아니라 '아직 관리 정보 없음' 상태이며 S13으로 선택적으로 연결.

│ ┌──────────────────────────────────┐ │
│ │           화분 사진              │ │
│ └──────────────────────────────────┘ │
│ 몬스테라 델리시오사 · 거실 창가       │
│ [건강 점검] [관리 기록] [사진 추가]   │
│                                      │
│ 관리 정보                            │
│ [기존 관리 정보 보기] 또는          │
│ [아직 없어요 · 직접 입력하기]        │
│                                      │
│ 오늘 확인할 일: 흙 상태 확인 [보기]  │

## 6. S07 · 건강 점검 **핵심 화면 (F05 필수)**

### 입력

```text
┌──────────────────────────────────────┐
│ < 건강 점검                          │
│ 대상: [몬스테라 A ▼ / 미등록 사진]   │
│ [증상 사진 추가하기]                 │
│ 어떤 증상이 보이나요?                │
│ [잎 갈변] [반점] [시듦] [해충 의심]   │
│ [기타/잘 모르겠음]                   │
│ 발견 시점 [알 수 없음 ▼]            │
│ 추가 설명 [_____________________]    │
│                                      │
│ 외부 AI에 사진이 전송될 수 있어요    │
│ [ ] 외부 전송 안내를 확인했습니다    │
│ [사진으로 점검하기]                  │
└──────────────────────────────────────┘
```

### 결과

```text
┌──────────────────────────────────────┐
│ < 건강 점검 결과                    │
│ 결과는 확정 진단이 아닙니다          │
│                                      │
│ 관찰된 증상: 잎 끝 갈변              │
│                                      │
│ 가능한 원인(예시)                    │
│ 1. 과습 가능성 · 추가 확인 필요      │
│ 2. 건조 스트레스 가능성              │
│                                      │
│ 먼저 확인할 내용                     │
│ □ 흙 상태를 직접 확인                │
│ □ 최근 물주기 기록 확인              │
│ □ 잎 뒷면 및 줄기 사진 추가           │
│                                      │
│ 불확실성: 사진만으로 원인 확정 불가   │
│ [이 화분에 결과 저장] [다시 점검]    │
└──────────────────────────────────────┘
```

**주의:** 결과 문구는 **레이아웃용 가상 예시**로서 실제 식물 진단이나 권고가 아니다. AI가 잘 모르겠다고 응답하면 '판단 어려움'을 표시. 분석 장애 또는 사진 전송 비동의 시 관찰 기록으로 돌아갈 수 있음.

## 7. S08 · 관리 행동 및 관찰 기록

```text
┌──────────────────────────────────────┐
│ < 관리 기록         몬스테라 A       │
│ 무엇을 했나요?                       │
│ [물 주기] [비료] [분갈이] [가지치기] │
│ [흙 확인] [잎 관찰] [기타]           │
│                                      │
│ 기록 날짜/시간 [11/09 20:30 ▼]       │
│ 상태/내용      [________________]    │
│ 메모           [________________]    │
│                                      │
│ [기록 저장하기]                      │
│ * '흙 확인'은 물 준 기록이 아닙니다.  │
└──────────────────────────────────────┘
```

**기능:** 실제 물을 준 경우에만 '물 주기' 로그 생성. 중복 제출 방지, 과거 날짜 선택 가능(정책은 기능서 검토).

## 8. S09 · 관리할 일

```text
┌──────────────────────────────────────┐
│ < 관리할 일                          │

│ 몬스테라 A · 흙 상태 확인            │
│ 예정일 11/09                         │

│                                      │
│ 스투키 · 잎 상태 관찰                │
│ 예정일 11/10                         │

```

**기능:** 완료·미루기·건너뛰기 구분. 실물 활동과 기록이 일치하도록 함.

## 9. S13 · 종별 관리 정보 직접 입력

```text
┌──────────────────────────────────────┐
│ < 몬스테라 관리 정보                 │
│ 관리 정보가 아직 없어요              │
│ [직접 입력하기]  ← 빈 입력 양식 열기  │
│                                      │
│ --- 입력 화면 ---                    │
│ [사용자 입력 · 검토 전]               │
│ 빛       [____________________]      │
│ 물       [____________________]      │
│ 온도     [____________________]      │
│ 흙       [____________________]      │
│ 주의사항 [____________________]      │
│ 참고 자료(선택) [____________]       │
│                                      │
│ [변경사항 저장] [검토 완료 승인]      │
└──────────────────────────────────────┘
```

**기능:** 버튼을 누르면 사용자가 내용을 직접 입력하는 양식이 열리며, AI 요청은 발생하지 않는다. 입력 정보의 검토 전/검토 완료를 구분하고 사용자 승인 없이 자동 승인하지 않는다. 동일 종의 관리 정보는 새 화분 등록 때 재사용.

## 10. 기타 화면의 구조

| 화면 | 주요 화면 구성 | 상태별 예외 |
|---|---|---|
| S01 개인 진입 | 앱 이름, 개인 사용자 접근, 오류 복구 | 미로그인/세션 만료/접근 불가 |
| S10 이력 | 사진 썸네일, 날짜·활동 유형, 상세 관찰, 날짜 필터 | 이력 없음, 사진 표시 실패, 기록 제거 확인 |
| S12 더보기 | 개인 데이터/사진 관리, 외부 분석·개인정보 안내, 사용량·알림 설정 | 데이터 삭제 경고, 외부 서비스 점검 불가 |

## 11. 데스크톱 배치 제안

```text
┌─────────────────────────────────────────────────────────┐
│ Die No More                             [개인 설정]    │
├──────────────┬──────────────────────────────────────────┤
│ 오늘         │ 현재 선택 화면 제목                       │

```

**적응 규칙:** 모바일은 단일 컬럼 + 하단 탐색, 데스크톱은 측면 탐색 + 화면 목적에 따른 1~2컬럼. 데스크톱에서도 데이터 입력과 건강 점검 결과의 의미는 동일.

## 12. 화면 상태 점검표 (설계 범위)

| 상태 | 적용 화면 | 화면에 있어야 할 내용 |
|---|---|---|
| 초기 데이터 없음 | S02/S11/S06/S13 | 빈 상태 설명과 다음 행동 |
| 카메라/파일 오류 | S03/S07 | 원인·지원 형식·재시도/수동 경로 |
| AI 대기 | S04/S07 | 처리 중 표시, 중복 실행 방지 |
| 분석 불확실 | S04/S07 | '판단 어려움', 수동 확인 및 추가 사진 |
| 서비스 장애/한도 초과 | S03/S07 | 비용 발생 없이 재시도 또는 일반 기능 계속 |
| 검토 전 관리 정보 | S06/S13 | 사용자 입력·검토 전 상태와 사용자 검토 동작 |
