# 2단계 · 기능별 사용 API

> **상태:** 초안 · 사용자 검토 전
> **관련:** [기능 명세](03-functional-specification.md) F02–F04, F10 · [화면 와이어프레임](02-wireframes.md) S03–S04, S13

## 기능별 사용 API

| 기능 | 명세 | 사용 API | 용도 |
|---|---|---|---|
| 식물 이름 검색 | F02, S03 | Perenual, Trefle | 이름으로 종 후보 조회 |
| 사진으로 종 식별 | F02–F04, S03 | Pl@ntNet | 사진으로 학명 후보 조회 |
| 종 관리 정보 조회 | F10, S04, S06 | Perenual | 물, 빛, 독성, 병해충 관리 가이드 표시 |
| 종 영문 일반명 조회 | F10, S04 | Perenual | 종 상세 정보의 영문명 표시 |
| 한국어 이름 표시 | F02–F04, S04 | Google Cloud Translation (개발 단계 1회 실행) | 영문 일반명을 한국어로 번역해 i18n 리소스 파일에 저장. 검색과 학명 매칭에는 쓰지 않음 |

## 데이터 연결 기준

- 후보는 **학명**을 기준으로 합치고 중복을 없앱니다. 별도 API는 쓰지 않고 앱 내부에서 처리합니다.
- 관리 정보는 학명으로 Perenual을 조회합니다. 값이 없으면 "정보 없음"으로 표시합니다. 값을 새로 만들지 않습니다.
- 관리 정보 값은 Perenual 응답을 사용하고, 항목마다 출처(Perenual)와 조회 날짜를 기록합니다.
- 한국어 이름은 개발 단계에서 Google Cloud Translation으로 한 번 번역하고, 사람이 검토한 뒤 i18n 리소스 파일로 커밋합니다. 앱 실행 중에는 번역 API를 호출하지 않습니다.
- 학명과 관리 정보 값은 번역하지 않습니다. 번역은 화면 표시용 이름에만 씁니다.

## 호출 위치

- Perenual, Trefle, Pl@ntNet은 모두 서버에서 호출합니다. API 키는 서버 환경변수에만 둡니다(`docs/03-architecture.md`).
- Google Cloud Translation은 개발 단계 번역 스크립트에서만 호출합니다. 앱 번들과 런타임에는 키를 두지 않습니다.
