# 2단계 · 기능별 사용 API

> **상태:** 초안 · 사용자 검토 전
> **관련:** [기능 명세](03-functional-specification.md) F02–F04, F10 · [화면 와이어프레임](02-wireframes.md) S03–S04, S13

## 기능별 사용 API

| 기능 | 명세 | 사용 API | 용도 |
|---|---|---|---|
| 식물 이름 검색 | F02, S03 | GBIF | 한국어 일반명·학명·품종명으로 종 검색 |
| 검색어와 종 매칭 | F03–F04, S04 | GBIF | 검색어를 학명 기준 종 키에 연결 |
| 종 관리 정보 조회 | F10, S04, S06 | Perenual | 물, 빛, 독성, 병해충 관리 가이드 표시 |
| 종 영문 일반명 조회 | F10, S04 | Perenual | 종 상세 정보의 영문명 표시 |
| 한국어 이름 표시 | F02–F04, S04 | 미정 | 사용 API 결정 후 기재 |

## 데이터 연결 기준

- 종의 기준 키는 **학명**입니다. GBIF에서 얻은 학명으로 Perenual을 조회합니다.
- 관리 정보 값은 Perenual 응답을 사용하고, 항목마다 출처(Perenual)와 조회 날짜를 기록합니다.
- 관리 정보 값이 없으면 "정보 없음"으로 표시합니다. 값을 새로 만들지 않습니다.

## 호출 위치

- GBIF와 Perenual은 모두 서버에서 호출합니다. API 키는 서버 환경변수에만 둡니다(`docs/03-architecture.md`).
