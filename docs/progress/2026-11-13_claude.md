## 세션 2 — 키 재확인

### 결정된 것
- [사용자 결정] Pl@ntNet 건강 점검 설명은 Google 번역으로 한국어로 보여주되 "기계 번역" 표시는 하지 않음. (Claude 구현 방침: 영어 원문·EPPO 코드는 함께 저장, 번역 결과 캐시.)

### 확인 결과
- 사용자가 Trefle 토큰 교체, Google 키 리퍼러 제한 해제 후 재확인: 둘 다 정상.
- Trefle 상세에 한국어 이름 있음(`common_names.ko` = "몬스테라"). Google 번역은 "Swiss cheese plant" → "스위스 치즈 식물".

### 승인 필요
- 한국어 이름 출처 순서: Trefle `ko` 우선, 없을 때만 Google 번역.
- [사용자 결정] 한국어 출처 원칙: API 데이터에 한국어가 있으면 우선 사용, 없을 때만 Google 번역(이름 등 모든 제공자 텍스트). ADR-0003의 "Google 번역으로 한국어 이름" 결정을 구체화.

## 세션 3 — PR #12 GPT 검토 반영

### 결정된 것
- [사용자 결정] 번역 제공자를 Azure Translator F0로 변경(GPT 대화에서 사용자가 요청, 이 세션에서 확인). Google은 화면에 Google 출처 배지를 의무로 요구해 "표시 없음" 결정과 충돌.

- [사용자 결정] Azure 가입이 지연되어 번역 연결은 구현 순서 맨 마지막. 다른 기능 먼저.
