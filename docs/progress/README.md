# 진행 기록 (docs/progress)

날짜별 작업 기록을 남기는 폴더입니다. 다음에 작업을 이어갈 때 가장 먼저 여기를 봅니다.

## 파일 이름

`YYYY-MM-DD_<작성자>.md`

- 작성자: `gpt`, `claude`, `skii`
- 예: `2026-11-09_claude.md`

작성자별로 파일을 나눠서 서로 다른 브랜치에서 작업해도 머지 충돌이 나지 않습니다.

## 규칙

- 파일은 **추가만** 합니다. 지난 날짜 파일은 고치지 않습니다.
- 정정할 내용은 그날 파일이 아니라 **오늘 파일**에 `정정:`으로 씁니다.
- 현재 상태는 **가장 최근 날짜 파일**에서 확인합니다.
- 한 파일은 한 작성자의 그날 기록입니다. 다른 작성자의 내용을 대신 쓰지 않습니다.

## 형식

```markdown
# YYYY-MM-DD · 작성자

## 한 줄 요약

## 진행한 일
- 항목 (관련 PR 또는 커밋)

## 결정된 것

## 아직 결정 안 된 것

## 다음 할 일
1.
```
