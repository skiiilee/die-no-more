## 추가: 규칙 변경 승인과 실제 호출 확인
- [사용자 결정] ADR-0006 전체 승인(D1–D6, 자유 입력 미전송 포함). ADR-0006 Status Accepted. `CLAUDE.md` 생성형 AI 기준과 ADR-0003 D5에 예외를 적음. S12 외부 사진 전송 안내에 건강 점검·AI(Google Gemini, 무료 등급 학습 가능성) 추가.
- Pl@ntNet 질병 식별 실제 호출(사용자 몬스테라 사진 2장, 2크레딧): 응답 형식은 문서와 같음. 최고 점수 약 0.07로 낮고, "Unknown parasitic pathogen"(ZZXXZZ)이 상위에 나옴 → 원인에서 항상 제외. 병 이름이 다른 식물 기준("Leaf spot of legumes")이라 그대로 보이면 헷갈림.
- [사용자 결정] `HEALTH_MIN_SCORE` 0.1: 약한 결과는 '판단 어려움' → AI 사진 판단으로 이어짐. F05 정확도 검증 때 다시 정함.
- Gemini 사진 판단 실제 호출(같은 사진, 사용자 승인): 형식 정상, 한국어 징후·가능한 원인·확인·행동. 금지 표현 없음. 3–10초. 첫 사진은 503(수요 많음) 3번 뒤 성공 → 무료 등급이 붐비면 "연결할 수 없음"이 나올 수 있음.
- 실제 호출은 저장소에 넣지 않은 임시 스크립트로 했고, 키는 출력하지 않음. 사진은 저장소 밖에 둠.
