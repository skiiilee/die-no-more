# 보류 항목 (조건이 생기면 다시 검토)

지금은 문제가 없어 **일부러 고치지 않은** 항목입니다. 버그나 미완성 작업이 아닙니다. 각 항목의 "다시 검토할 때"에 적힌 조건이 생기면 열어 봅니다.

- 새 항목은 표 아래에 추가하고, 처리한 항목은 지우지 않고 상태를 바꿉니다.
- 상태: `보류`(조건 미발생) · `검토 중` · `처리됨`(관련 PR 기재) · `폐기`

|---|---|---|---|---|---|---|
