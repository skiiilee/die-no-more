# 검토 메모: S07 결과의 AI 설명과 기존 규칙의 충돌 (2026-11-22)

## 무엇이 충돌하나
- 사용자 선택(2026-11-22): S07-B의 '추가 확인 항목'·'안전한 다음 행동'을 AI 설명으로 채운다.
- `CLAUDE.md`: "생성형 AI는 근거가 있는 설명에만 쓰고, 검증되지 않은 진단에는 쓰지 않는다."
- ADR-0003 D3: MVP에 LLM 설명 기능을 두지 않는다(ADR-0005가 관리 정보 보완에 한해 예외).

## Claude의 처리
요구를 조용히 바꾸지 않고, 진단이 되지 않도록 묶어서 구현했다. 최종 채택은 사용자가 ADR-0006을 승인할 때 정해진다.
- AI는 사진을 보지 않고 Pl@ntNet이 준 후보만 '가능성'으로 설명한다. 새 원인·확정·약제·처치는 금지하고, 응답에서 그런 글은 버린다.
- 고정 확인 항목과 안전 행동은 항상 보여 준다. AI는 덧붙이는 참고이며 'AI 생성'으로 표시한다.
- 자유 입력(추가 설명)은 AI에 보내지 않는다. Gemini 무료 등급은 입력을 학습에 쓸 수 있다(ADR-0005 D1). 이 부분은 사용자의 원래 선택보다 보수적으로 정했다.

## 추가 요청: '판단 어려움'일 때 AI가 사진으로 다시 판단 (2026-11-22)
- 사용자 요청: 진단 결과가 없을 때 AI를 호출해 다시 진단.
- Claude가 알린 점: AI가 사진을 보지 않으면 증상 선택지만 보고 짐작하게 되고, 사진을 보내면 ADR-0003 D5(사진은 Pl@ntNet에만)와 `CLAUDE.md` 기준을 바꿔야 한다. 무료 등급은 사진을 학습에 쓸 수 있다.
- 사용자 선택: AI에 사진도 보내 판단(세 가지 선택지 중).
- 구현(ADR-0006 D6): '판단 어려움'일 때만, 요청마다 별도 동의(받는 곳·모델·학습 가능성 명시), 자유 입력 제외, 가능성으로만 표시, 처치·확정 표현 제거, 'AI 생성'.
- 승인 시 `CLAUDE.md` 수정 제안: "생성형 AI는 근거가 있는 설명에만 쓰고, 검증되지 않은 진단에는 쓰지 않는다. 예외: ADR-0006 D6(건강 점검 '판단 어려움' 때 사용자가 동의한 AI 사진 판단, 가능성으로만 표시)." 이 PR에서는 `CLAUDE.md`를 고치지 않았다.

## 대안
1. ADR-0006 승인: 현재 구현 그대로.
2. 거절: AI 요청을 끄고 고정 항목만 보여 준다. 코드 변경은 결과 화면에서 설명 요청을 빼는 정도.
3. 부분 승인: 원인 설명만 AI로, 확인 항목·행동은 고정 문구만.

## 사용자 결정 필요
- ADR-0006 승인 여부(위 1–3).
- 자유 입력을 AI에 보내지 않는 결정에 동의하는지.
- ADR-0006 D6 승인 여부와, 승인하면 `CLAUDE.md`·ADR-0003 D5에 예외를 적는 것.
