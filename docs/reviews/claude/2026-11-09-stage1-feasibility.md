## 3. F05 건강 점검이 1차 필수일 때의 조건

1. **정확도 검증이 출시 관문이다.** 검증 전에는 공개하지 않는다. 검증 방법은 사용자 사진을 대상으로 사용자가 정답 원인을 판정하는 방식을 권한다.
2. **통과 기준은 2단계에서 정한다.** 숫자 기준(예: 정답 원인이 상위 후보 안에 포함되는 비율)은 기능 정의 단계에서 확정한다.
3. **진단처럼 보이지 않게 한다.** 확정 진단 표현을 금지하고, 가능한 원인과 추가로 확인할 관찰 항목을 함께 보여준다.
4. **외부 전송 동의와 개인정보.** 실내 사진이 외부 서비스로 전송되므로 동의 범위와 주기는 2단계에서 정한다.
5. **테스트 사진 관리.** 개인 사진은 저장소에 올리지 않는다. 로컬이나 private 저장소에만 둔다.

## 4. 아직 결정이 필요한 항목 (사용자 결정 대기)

- 건강 점검 통과 기준의 숫자 (2단계 기능 정의에서 확정 가능)
- 수동 종 검색의 데이터 출처 (자유 입력 후 나중에 학명 연결 여부)
- 같은 종 판정 기준과 한국어 별칭 처리

## 5. 1단계 판정

- 기능 범위는 실현 가능하다.
- 실내 식물 위주 지원으로 식별 정확도 검증 대상을 좁힌다.
- 건강 점검은 정확도 검증 결과에 따라 출시 여부가 달라지므로, 2단계 기능 정의에 검증 절차를 포함해야 한다.
