# Die No More — 기능 검토안

상태: **Draft / 기능 검토용**  
기준: 기존 PR #1의 MVP 요구사항(F01–F18)과 사용자 대화에서 확인한 운영 방식.  
**범위:** 이 문서는 *무슨 기능이 어떻게 동작해야 하는지*만 검토한다. UI 시안·와이어프레임·화면 배치·코드·DB 스키마·인증 기술·배포 및 개발 환경 설계는 포함하지 않는다. 별도의 UI/기술 설계 승인 전에는 구현하지 않는다.

## 1. 확인된 사용자 요구

- 개인적으로 사용하는 **브라우저 기반 식물 관리 웹사이트**이며, 향후 GitHub Pages를 통해 접속하는 것이 목표다. 이 문서에서 배포 방식 자체를 설계하지는 않는다.
- 식물 20종 등을 **미리 채워두지 않는다**. 새 식물을 등록하면서 종별 관리 정보가 쌓이도록 한다.
- 동일 종의 화분은 종별 관리 지식을 재사용하지만, **개별 화분의 별명·사진·관리 기록은 구분**한다.
- 당분간은 **기능 검토만** 진행한다. UI 설계와 코드 구현은 별도 단계다.

## 3. 종별 관리 정보가 쌓이는 동작

1. 사용자가 사진 식별 결과를 확인하거나 식물 이름을 직접 선택한다.
2. **같은 종의 관리 정보가 있으면 기존 내용을 재사용**한다. 화분별 관리 이력은 합치지 않는다.
3. 관리 정보가 없으면 외부 AI(Gemini 후보)를 통해 **초안을 생성하는 기능을 검토**한다. 생성 여부는 사용자가 이해할 수 있어야 하고, AI 생성 정보는 검증된 사실처럼 표시하지 않는다.
4. 사용자는 관리 정보의 오류를 수정할 수 있고, 검증되지 않은 항목을 식별할 수 있어야 한다. 관리 기준은 고정된 '7일마다 무조건 물주기'보다 **실제 흙 상태·환경·관찰**을 우선한다.
5. AI가 실패하거나 무료 한도를 초과해도 **식물 등록, 조회, 관리 기록을 계속 사용할 수 있다**.

## 4. 외부 기능 사용 시 기대 행동

- **식물 식별**: Pl@ntNet은 후보 서비스일 뿐 최종 확정은 아니다. 식별 실패, 오식별, 종 이름 부족을 수동 등록으로 보완한다.
- **건강 점검·관리 초안**: Gemini는 후보이며, 전문 병해 진단이 아니므로 불확실성 및 실제 관찰 질문을 표시한다.
- **무료 한도 소진**: 자동 유료 전환·과금 없이 해당 외부 분석만 중단하고 사용 가능한 일반 기능은 유지하는 것을 기본 사용자 경험으로 검토한다. 실제 서비스별 과금 설정의 안전성 확인은 후속 단계다.
- **사진 개인정보**: 외부 AI에 실내 사진이 전송될 수 있다는 점을 사용자에게 알리고, 원치 않으면 전송 없이 수동 등록하도록 한다.
- **오프라인 사용**: 오프라인 상태 표시와 실패 안내는 필요하나, 오프라인 상태의 수정·기록 자동 동기화는 초기 범위 밖으로 둔다.

## 5. 기능 인수 시나리오

- [ ] 사진 식별 성공 → 사용자 종 확인 → 화분 등록까지 이어진다.
- [ ] 사진 인식 실패 또는 카메라 거부 → 이름 입력 또는 미상 식물 등록이 가능하다.
- [ ] 새로운 종 최초 등록 → 필요 시 미검증 관리 초안 제공 → 사용자 검토·수정 → 이후 재사용한다.
- [ ] 같은 종의 두 번째 화분 등록 → 관리 정보는 재사용하지만 두 화분의 활동 기록은 분리된다.
- [ ] 관리 정보 생성 실패·무료 한도 초과 → 화분 등록과 수동 기록이 막히지 않는다.
- [ ] 흙 확인만 완료 → 물주기 실행 기록을 자동으로 만들지 않는다.
- [ ] 실제 물주기를 기록 → 중복 완료로 관리 이력이 두 번 생성되지 않는다.
- [ ] 사진 기반 건강 점검 → 질병을 확정하지 않고 가능한 원인과 추가 관찰 항목을 제시한다.
- [ ] 사용자 사진·관리 기록 → 다른 사람에게 노출되지 않는다.

## 6. 결정이 남은 기능 질문

1. **F05 건강 점검**을 1차 사용 범위에 포함할지, 검증된 경우에만 제한적으로 켤지.
2. 신규 종의 **AI 관리 초안**을 자동 제안할지, 사용자가 버튼으로 요청할지.
3. AI 관리 정보를 사용자가 수정한 뒤 어떤 상태에서 **검토 완료**로 간주할지.
4. 사진 분석에 필요한 **외부 전송 동의**를 어떤 범위와 주기로 요청할지.
5. 우선 지원할 식물 종류(관엽식물·다육식물·허브·야외 식물)와 미지원 종에 대한 안내 기준.

이 질문들은 **기능 검토를 위한 미결정 사항**이며, 구현 기술이나 화면 설계 승인을 뜻하지 않는다.
